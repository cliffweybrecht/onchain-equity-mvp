# Rail Protocol — Repository Structure

Canonical reference for directory purposes, classifications, editability rules, and governance boundaries.

---

## Classification Definitions

| Classification | Meaning |
|---|---|
| **source** | Actively maintained code or configuration. Manual editing is the normal workflow. |
| **source (non-canonical)** | Present in the repository but not part of the current canonical deployment. Must be labeled as a parallel experiment. |
| **canonical evidence** | Chain-grounded proof artifacts derived from on-chain transactions. Never manually edited. |
| **generated output** | Produced by tooling (compilers, package managers). Never manually edited. Often gitignored. |
| **historical artifact** | Produced by prior phases and retained for audit continuity. No modification. |
| **deployment state** | Records of on-chain deployments. Updated only when a new deployment is executed and evidenced. |
| **documentation** | Human-authored reference material. Must accurately reflect canonical state. |
| **configuration** | Tooling configuration. Changes have downstream effects; review carefully. |

## Governance Boundaries

### What requires chain-grounded evidence before becoming canonical

- Any change to a deployed contract address
- Any change to admin authority (Safe owner, contract admin roles)
- Any update to `deployments/base-sepolia.json`

### What must never be modified after creation

- Artifacts in `contracts/evidence/` and `evidence/`
- Artifacts in `manifests/`
- Files in `archived/` and `archived-tests/`

If a canonical evidence artifact must be corrected, open a dedicated PR that includes the original artifact and a written explanation of the error. Do not silently overwrite.

### What requires a parallel-experiment label

Any Solidity file that is not part of the current canonical deployment must carry a top-of-file comment:

```solidity
// PARALLEL EXPERIMENT — not part of the canonical Phase 8.4.C stack.
// Do not reference this contract in canonical governance documents.
```

See `docs/TERMINOLOGY.md` for the definition of *parallel experiment* and *canonical*.
